# Требования к первым двум спринтам

Первый спринт охватывает US-01–US-04 и US-10, второй — US-05–US-09 по основной таблице отчёта `Отчет_ТРПО_Agile.pdf`.

| История | Критерии и реализация |
| --- | --- |
| US-01. Создание | «Новая заметка» сразу отправляет POST; после подтверждения запись открыта в редакторе. По умолчанию используется «Личное». Пустой заголовок заменяется на «Без названия». Пустой текст допустим. |
| US-02. Список и открытие | GET списка возвращает карточки; выбор загружает заголовок, полный текст и чек-лист отдельным GET. Пустой список содержит сообщение и действие создания. PostgreSQL и постоянный volume сохраняют записи между открытиями приложения. Поздний ответ предыдущего открытия не меняет текущий выбор. |
| US-03. Редактирование | Редактор изменяет заголовок и текст выбранной записи. PUT обновляет только эту заметку, сохраняя ID, блокнот и дату создания. После подтверждения и перезагрузки видны новые значения. |
| US-04. Автосохранение | Таймер сбрасывается при каждом изменении; через 1000 мс после последнего ввода отправляется текущий черновик. Одновременно выполняется один запрос записи; последующий ввод сохраняется отдельно. «Сохранено» видно только после ответа сервера и при отсутствии новых изменений. Ошибка сохраняет ввод и показывает действие повтора. |
| US-04. Переход | Выбор другой заметки или создание новой немедленно отправляет изменения. Переход ждёт подтверждения всех текущих правок. При ошибке диалог блокирует переход до успешного повтора или явного «Не сохранять»; «Остаться» сохраняет ввод в редакторе. |
| US-05. Корзина | Удаление переводит заметку в корзину и исключает её из рабочего списка, поиска и фильтров. Блокнот, текст, теги и отметки сохраняются после перезагрузки. |
| US-06. Восстановление | Заметка покидает корзину и возвращается в исходный блокнот. Другие заметки сохраняют прежнее состояние. |
| US-07. Блокноты | Можно создать блокнот с непустым названием, выбрать его, создавать в нём заметки и переносить туда существующие. Фильтр блокнота показывает только его активные заметки. |
| US-08. Теги | Можно назначить имеющийся или новый непустой тег и снять назначение. Имена тегов сравниваются без учёта регистра. Фильтр тега показывает только связанные с ним активные заметки. |
| US-09. Поиск | Поиск по вхождению в заголовок и текст выполняется без учёта регистра. Он учитывает оба фильтра и исключает корзину. Пустой запрос сбрасывает поиск. При отсутствии совпадений показано сообщение. Норматив на 1000 заметок — до 2 секунд. |
| US-10. Чек-лист | Кнопка или Enter добавляет пункт с непустым после обрезки пробелов текстом. Отметки устанавливаются и снимаются независимо. Массив пунктов и отметки входят в автосохранение и восстанавливаются после перезагрузки. |

## API и хранение

API заметок поддерживает список с поиском и фильтрами, создание, чтение, автосохранение, изменение блокнота и тегов, корзину и восстановление. Полная заметка содержит `content` со строками задач `- [ ]` и `- [x]`, блокнот, теги и дату попадания в корзину. Миграция переноса прежних списков добавляет пункты в текст в исходном порядке и сохраняет отметки.

Повтор создания использует один UUID и неизменный исходный POST; введённые до подтверждения изменения затем отправляются PUT той же заметки. Это предотвращает дублирование после потери ответа. Черновик хранится отдельно от последнего подтверждённого состояния. PUT передаёт версию заметки. Если другая вкладка сохранила более новую версию, сервер отклоняет устаревшую запись. Редактор оставляет черновик, пока пользователь явно не откажется от него. Повтор создания сравнивается с исходным запросом независимо от последующих правок.

Заголовок ограничен 200 символами, а текст с задачами — 2 610 000 кодовыми единицами UTF-16. Пустой пункт удаляется при завершении редактирования строки.

## Дополнения к первой версии

Чек-лист находится внутри текста заметки. Галочка меняет отметку, нажатие на подпись открывает редактирование, а очистка строки и выход из поля удаляют пункт. Заголовки уникальны в пределах блокнота без учёта регистра. Для занятых названий сервер выбирает свободный номер. При обновлении базы самая ранняя заметка сохраняет исходное имя, остальные дубли получают номера.

## Вне области

Экспорт и импорт данных относятся к третьему спринту. Учебная версия рассчитана на одного пользователя и серверное хранение.
